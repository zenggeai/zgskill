# 制作与验收规范

## 默认规格

- 中文竖屏口播默认：1080×1920、30fps、H.264 视频、AAC 48kHz 音频；
- 保持源视频人物比例，不拉伸，不为铺满画面裁掉头部或关键手势；
- 输出独立 SRT，并使用同一校对时间轴烧录字幕；
- 输出视频号 9:16 封面；用户涉及小红书或抖音时另输出 1080×1440 的 3:4 封面。

若用户或源素材明确要求其他规格，以用户要求和源素材为准。

## 项目结构

建议在素材目录下建立：

```text
edit/
├── project.md
├── edl.json
├── transcripts/
├── downloads/
├── graphics/
├── music/
├── navigation/
├── covers/
├── verify/
├── master.srt
└── final.mp4
```

目录名称可以适配现有项目，但原片、成片、中间文件和验收证据必须能区分。

## 转写与剪辑

1. 检查原片时长、分辨率、平均/真实帧率、旋转信息、视频起点、音轨起点、采样率、声道和响度。
2. 转写需要带时间戳。已有缓存且原文件未变化时复用，不重复转写。
3. 音频存在起始偏移时，只补偿一次。剪辑后用短片段转写或波形交叉检查剪口附近语义。
4. EDL 至少记录：源文件、源入点、源出点、输出起点、时长、保留或删除原因。
5. 剪口落在词语或自然停顿边界，前后保留约 30–200ms 缓冲；音频剪口增加约 30ms 淡入淡出，避免爆音。
6. 画面和声音必须使用同一剪辑范围，不能独立剪出同步漂移。
7. 只删用户允许删除的内容。压缩时长不能删掉纠错句、适用条件、风险提示和结论所需的因果链。

## 字幕

- 校对人名、公司名、产品名、数字和专业术语；
- 一至两行为主，按语义换行，不拆固定词组；
- 字幕在所有图卡和运动图形之后最后合成；
- 竖屏字幕需要避开人脸、下巴、底部平台按钮和左右裁切区；
- 用实际字体测量长字幕宽度，不只凭字符数估算；
- 抽查开头、结尾、每个剪口和最长字幕。

## 事实核验与素材

涉及近期事件、公司数据、法律政策、人物身份、研究实验和可能变化的信息时联网核验。优先级：

1. 官方公告、监管文件、年报、论文、机构官网；
2. 当事公司或人物的原始公开表达；
3. 原创媒体报道；
4. 聚合、转载和搜索摘要只作发现入口。

素材表至少包含：

```text
出现位置 | 口播内容 | 素材类型 | 本地文件 | 来源页 | 原图链接 | 图注 | 日期 | 授权边界
```

图片通常显示 3–6 秒。横图在竖屏中以完整卡片或安全裁切呈现，不能拉伸。网页截图保留站点身份、标题、日期和关键句，不仿造官网页面。自制数据卡必须标注数据来源和统计口径。

## 图卡与导航

- 图卡服务于口播，不永久遮住人物；
- 事实卡、观点卡、假设卡在视觉文案上明确区分；
- 视频超过 3 分钟或包含 3 个以上明确部分时，建议增加章节导航；
- 导航显示当前章节、章节序号和连续进度，章节名控制在 4–10 个汉字；
- 不把所有长标题永久塞进导航；
- 需要时写入 MP4 章节元数据，并输出章节时间表；
- 画面导航不是平台可点击控件，是否支持跳转取决于发布平台。

## 配乐与混音

- 知识口播默认选择无歌词、克制、现代、轻科技或纪实感音乐；
- 避免强鼓点、宏大预告片感和抢占注意力的主旋律；
- 开头渐入、结尾渐出，循环与段落之间使用交叉淡化；
- 人声出现时自动压低配乐，优先保证每句话清楚；
- 默认参考最终综合响度约 -16 至 -14 LUFS，真峰值不高于 -1 dBTP；源音条件不允许时优先不削波并报告实测值；
- 生成音乐的“无歌词”设置不是人工听审证明。不能播放全片时只报告技术测量与结构检查。

## 封面

封面标题应具体、可理解，并与普通人的利益或问题相关，但不得改变事实口径。用户已经给标题时逐字使用，不自动加标点、身份或数字。

封面要求：

- 使用本次视频中的真人或用户指定图片；
- 独立封面不带视频导航、时间码和口播字幕；
- 标题字少、字号大、手机缩略图可读；
- 人物头脸完整，不把评论者误标成新闻人物；
- 上下保留约 15%–20% 安全空间，关键文字不贴边；
- 生成后实际查看 9:16 和 3:4 两种比例，逐字核对标题并检查裁切。

## 渲染顺序

推荐顺序：

```text
按 EDL 提取片段
→ 片段级画面处理
→ 合成真实素材与图卡
→ 合成章节导航与进度条
→ 拼接连续画面
→ 混合人声与配乐
→ 最后烧录字幕
→ 写入章节和媒体元数据
→ 导出最终 MP4
```

如果现有工具需要不同顺序，仍要保证字幕不会被后续素材遮挡，音画时间轴不会漂移，最终文件只进行必要编码。

## 强制验收

最终 MP4 至少执行：

1. `ffprobe` 或等价回读：时长、尺寸、帧率、编码、声道、采样率、帧数和章节数；
2. 从头到尾完整视频/音频解码；
3. 综合响度、响度范围和真峰值测量；
4. 开头与结尾抽帧；
5. 每个剪口前后抽帧或短片段检查；
6. 每个章节切换、素材类型首次出现、最长字幕和封面抽查；
7. 必须保留内容与结尾署名检查；
8. 外部素材来源和身份检查。

出现错误后修复、重新导出、重新验收。渲染命令退出成功、文件存在、上传进度完成或播放器能打开，都不能单独证明成片合格。

## 交付记录

验收记录写清：

- 成片文件名、时长、尺寸、帧率、编码、帧数和文件大小；
- 剪掉与保留的内容；
- 字幕数量和校对说明；
- 配图、导航、音乐与封面说明；
- 综合响度和真峰值；
- 完整解码和抽帧结果；
- 事实修正、资料图身份和授权限制；
- 是否人工全片试听；
- 是否上传或发布。
